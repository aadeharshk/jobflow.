> **Status:** preliminary, research only. **Nothing was purchased or registered.** JobFlow stays the provisional name until the owner approves a final brand.
> **Date:** 2026-11-26. **Not legal advice.** A trademark attorney or agent should run a formal clearance search before branding spend.

**npm:** `jobflow` is unclaimed, but **`@jobflow/jobflow-mcp`** exists ("MCP server for JobFlow - AI-powered job application tracker"), so the `@jobflow` scope is taken by a same-category product.

## Assessment

**High risk** for a distinctive, defensible brand: multiple same-category "JobFlow" projects, the GitHub org name and the npm scope are already taken. Even without a registered trademark conflict, the name has weak SEO differentiation and invites confusion. Users searching "JobFlow AI job" would find competitors.

## Manual next steps for the owner (≈30 minutes, free)

1. **India:** search wordmarks in Class 9 (software) and 42 (SaaS) at the IP India public search (`ipindiaonline.gov.in` → Trade Marks → Public Search).
2. **Global:** WIPO Global Brand Database; USPTO trademark search; EUIPO eSearch.
3. **Domains:** check `.com`, `.in`, `.ai`, `.app` at a registrar (no purchase until approved).
4. **Social handles:** X, LinkedIn page, Instagram, Product Hunt.
5. Decide. A rename is cheap now: the name appears only in UI copy, docs, `package.json` and `wrangler.jsonc` `name`.
